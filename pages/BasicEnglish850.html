没有匹配的词
怎么用这 850 词：Ogden 的核心不是背单词，而是用有限的词 + 规则去组合表达无限的意思。
· 名词可加 -s / -es 变复数（feet、teeth 等不规则形也允许）；
· 300 个名词可加 -er / -ing / -ed 造新词（如 work → worker、working）；
· 形容词可加 -ly 变副词、-er / -est 变比较级与最高级；
· 50 个反义形容词可用 un- 取反（如 happy → unhappy）；
· 18 个操作动词可做时态变化（be / do / have / come / go / see / seem / give / take / make / get / keep / let / put / send / say / may / will）。

中文释义为便于理解的简要对应，实际词义随语境变化。
